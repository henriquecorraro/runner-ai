# Example Ecosystem

This folder shows a generic centralized ecosystem layout for the runner.

It is only a reference model and contains no real repositories, tasks, or business context.

## Included Example Pieces

- `ecosystem.config.json`: sample repository registry and agent setup
- `sdd/README.md`: sample centralized SDD notes
- `sdd/tasks/`: placeholder task queue
- `runs/`: placeholder run history folder
- `skills/`: placeholder ecosystem-specific skills folder
