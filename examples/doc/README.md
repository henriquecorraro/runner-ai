# Example Human Docs

This folder shows a generic example of repository-local human documentation.

It does not represent a real product, repository, route, or business rule.

Use it as a style reference for documentation that should live inside the code repository that owns the behavior.

## Suggested Reading Order

1. `docs/README.md`
2. `docs/architecture/system-overview.md`
3. `docs/features/example-feature.md`

## Intent

The example is meant to show:

- a clear entry point
- stable architecture notes
- feature-level behavior documentation
- human-readable maintenance guidance
