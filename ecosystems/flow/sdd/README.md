# Flow Ecosystem SDD

This folder centralizes the SDD for the Flow ecosystem.

The repositories remain the source of code and repo-local documentation. The ecosystem SDD is the source of planning, task grouping, scope ownership, and cross-repo execution for the runner.

## Structure

- `tasks/`: executable ecosystem tasks
- use the shared `ecosystem-task-factory` skill for task creation and splitting
